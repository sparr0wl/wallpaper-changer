# Wallpaper changer

Нативное приложение Qt 6 для видеофона главного меню и шрифтов **Dota 2**.
Один интерфейс в Windows и Linux: библиотека с превью, добавление видео кнопкой **+**,
автоматическое MP4 → WebM, подгонка под монитор и актуальный фикс события.
В Omarchy цвета берутся из текущей темы; на других системах используется встроенная тёмная палитра.
Quickshell для запуска больше не нужен.

Релиз: **`7.41f+Trove_of_Terror`**. Это обозначение поддерживаемой версии игры/события;
совместимость с будущими патчами не гарантируется.

## Установка

Файлы доступны в [GitHub Releases](https://github.com/sparr0wl/wallpaper-changer/releases).
Архитектура готовых пакетов — **x86-64**.

| Система | Файл | Установка |
|---|---|---|
| Windows 10 1809+ / 11 | `*-windows-x86_64-setup.exe` | Запустить установщик; права администратора не нужны |
| Windows, переносной вариант | `*-windows-x86_64-portable.zip` | Распаковать всю папку и запустить `wallpaper-changer.exe` |
| Debian 12+ / Ubuntu 24.04+ | `*.deb` | `sudo apt install ./wallpaper-changer-*.deb` |
| Fedora 42+ | `*.rpm` | `sudo dnf install ./wallpaper-changer-*.rpm` |
| Omarchy / Arch и другой современный Linux | `*-linux-x86_64.tar.gz` | Распаковать архив и выполнить `./install.sh` |

После установки запускайте **Wallpaper changer** из Applications или командой:

```bash
wallpaper-changer
```

В Windows установщик добавляет каталог приложения в пользовательский PATH: откройте
новый терминал после установки. Переносной Windows ZIP PATH не меняет.

Linux использует системные Qt 6.4+, Python 3.10+, FFmpeg и LZ4. DEB/RPM объявляют зависимости
для пакетного менеджера. Для Omarchy/Arch нужны `qt6-base`, `qt6-declarative`, `qt6-multimedia`,
`qt6-wayland`, `python`, `ffmpeg`, `lz4`. В Windows Python, FFmpeg и Qt уже входят в сборку.
У Fedora свободная сборка FFmpeg может не поддерживать отдельные патентованные кодеки;
для таких входных видео нужен FFmpeg с соответствующим декодером.

## Первый фон

1. Закройте Dota 2. Установленную через Steam игру приложение найдёт автоматически.
2. Нажмите **«+ Добавить видео»** и выберите MP4, WebM, MKV или другой формат FFmpeg.
3. Приложение сохранит исходник, создаст превью, преобразует видео, соберёт фикс и установит фон.
4. Запустите Dota 2. Уже добавленные фоны переключаются кнопкой **«Применить фон»**.

На новом компьютере при первом применении приложение попробует скачать основу видеофона
из авторских гайдов. В сборку чужие игровые ресурсы не включены. Если ссылка недоступна,
скачайте совместимую основу из [исходного гайда](https://steamcommunity.com/sharedfiles/filedetails/?id=3360663587)
и выберите её в **«Настройки → Подробности и пути → Выбрать основу»**.
Подходит папка с VPK готового фона или распакованная основа с `123/` и `panorama/`.

Видео растягивается до физического разрешения монитора без добавления полос. Пропорции
исходника при необходимости меняются. Уже записанные в видео полосы не удаляются.
Используется VP9/WebM, 30 кадров/с, без звука, с ограничением результата до 20 МБ.
Длительность сохраняется; при чрезмерно длинном ролике приложение просит выбрать короче.
Исходники — до 2 ГиБ. Разрешение можно переопределить в настройках.

## Подключение ресурсов и фикс Trove of Terror

`-language 123` больше не требуется: старая произвольная папка `dota_123` не подключается
актуальной игрой. Ресурсы устанавливаются отдельным VPK в штатную папку аудиоязыка,
например `game/dota_russian/pak30_dir.vpk`. Чужие VPK и файлы озвучки не перезаписываются.

Если аудиоязык английский, выбирается существующая языковая папка без скачанной озвучки,
чтобы игра использовала английскую речь из основных файлов. **Язык текста сохраняется.**
Для миграции старой настройки закройте также Steam: его параметры не должны перезаписываться
из памяти. Старое значение LaunchOptions сохраняется отдельно; остальные параметры не меняются.

В текущем dashboard игра выбирает:

```text
panorama/layout/dashboard_background_monster_hoard_2026.vxml_c
```

Это внутреннее название **Trove of Terror**, подтверждённое токеном локализации
`DOTA_MonsterHoard2026_TreasureTitle`. Фикс берёт `panorama/layout/dashboard.vxml_c`
из установленной игры и меняет только ссылку на сцену в блоке LaCo/KV3 v5.
Остальные блоки и числовые данные сохраняются. После обновления игры доступна кнопка
**«Обновить фикс события»**, сохраняющая видео без перекодирования.

Оригинальные VPK, `gameinfo.gi` и подписи игры не изменяются. Прошлая собственная установка
сохраняется в `game/.dota-background-backups/`. При отключении фона удаляются из пути загрузки
только принадлежащие приложению архивы и восстанавливается прежний аудиоязык, если пользователь
не менял его самостоятельно. При неизвестном формате ресурсов автоматический фикс останавливается.

## Шрифты и данные

Вкладка **«Шрифты Dota»** управляет свободно лежащими файлами из `game/dota/panorama/fonts`.
Отключение сохраняет резервную копию с SHA256, включение восстанавливает проверенные байты.
Новая версия шрифта от Steam не заменяется старой копией. Нужен перезапуск игры.
Системные шрифты и шрифты самого приложения не переключаются.

Данные и библиотека:

- Linux: `~/.local/share/dota-background-changer/` — прежний путь сохранён для совместимости.
- Windows: `%LOCALAPPDATA%\WallpaperChanger\`; старая папка `.local/share/dota-background-changer`
  в профиле пользователя, если уже существует, продолжает использоваться.
- `DOTA_BACKGROUND_STORAGE` позволяет явно задать другой каталог.

Удаление программы не удаляет библиотеку, шрифтовые копии и игровые резервные копии.
Omarchy определяется по установленной команде и файлам темы в `~/.local/state/omarchy/current/`.
Название темы показывается только при доступной интеграции Omarchy.

## Сборка из исходников

Нужны C++17, CMake 3.21+, Qt 6.4+ с Quick/Controls/Dialogs/Multimedia и Python.

```bash
git clone https://github.com/sparr0wl/wallpaper-changer.git
cd wallpaper-changer
cmake -S . -B build/native -DCMAKE_BUILD_TYPE=Release
cmake --build build/native --parallel 4
./build/native/wallpaper-changer
```

Для пользовательской установки в Omarchy/Linux выполните `./install-user.sh`.
Она создаёт команду в `~/.local/bin` и ярлык в `~/.local/share/applications`.
Системная панель, `/usr/share/omarchy` и конфигурация Hyprland не редактируются.

```bash
python3 -m unittest discover -s tests -v
python3 tests/smoke_ui.py --fixture
./build/native/wallpaper-changer --self-test
```

`--self-test` проверяет VPK, LZ4 и настоящую конвертацию MP4 без Steam и графического сеанса.
UI-тест использует стандартное окно Qt и проверяет все вкладки, сохранение карточек при
фоновом обновлении и сохранение позиции списка шрифтов. Игровые файлы в тестах не меняются.

Утилиты архивов остаются доступны из исходников:

```bash
python3 -m dota_background list /path/pak01_dir.vpk --filter panorama/layout
python3 -m dota_background extract /path/pak01_dir.vpk ./extracted --entry panorama/layout/dashboard.vxml_c
python3 -m dota_background pack ./assets ./new.vpk
python3 -m dota_background --help
```

## Автоматический релиз

`.github/workflows/release.yml` собирает DEB/RPM в Debian 12 и проверяет RPM в Fedora.
На Windows собираются Qt-интерфейс, замороженный Python-сервис и установщик Inno Setup;
проверяются установленная программа и удаление. Только после успешных проверок публикуются
артефакты и `SHA256SUMS` с тегом **`7.41f+Trove_of_Terror`**.

Workflow запускается при push в `main` для проверок; публикация разрешается коммитом с
`[release]` в сообщении либо ручным запуском workflow. Уже существующий релиз не перезаписывается.
Версии зависимостей Windows закреплены в workflow. Linux-архив собирается с glibc Debian 12,
а не с более новой glibc Arch.

`native/` — оболочка Qt, `qml/` — интерфейс, `dota_background/` — операции с видео и игрой,
`packaging/` — установщики, `tests/` — проверки. Подробности внешних компонентов — в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
