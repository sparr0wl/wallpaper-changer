# Wallpaper changer

Самостоятельное приложение Quickshell для видеофонов главного меню и шрифтов Dota 2.
Обычное окно с библиотекой, превью и цветами активной темы Omarchy.

## Запуск

Клонируйте проект и запустите его из папки исходников:

```bash
git clone https://github.com/sparr0wl/wallpaper-changer.git
cd wallpaper-changer
./start.sh
```

Зависимости на Linux: Python 3.10+, Quickshell, Qt Quick Controls/Dialogs/Multimedia,
FFmpeg (`ffmpeg` и `ffprobe`), системная `liblz4`.
На системах без Quickshell остаётся запасное окно GTK; на Windows — прежнее окно Tk.
Новое оформление и описанный ниже упрощённый сценарий предназначены для Linux/Quickshell.

`./install-desktop.sh` устанавливает пользовательский ярлык. Системные файлы Omarchy,
конфигурация topbar и правила окон не изменяются.

## Первый запуск на другом компьютере

Репозиторий содержит только исходники: видео, VPK, шрифты и игровые ресурсы не включены.
Нужна установленная Dota 2 и совместимая основа видеофона. Скачайте основу по ссылке
в [исходном гайде](https://steamcommunity.com/sharedfiles/filedetails/?id=3360663587) либо
попробуйте автоматическую загрузку:

```bash
./start.sh download-template ./template
```

ZIP готового фона можно подготовить командой `./start.sh import-zip ./background.zip ./template`.
Укажите полученную папку в **«Настройки → Подробности и пути → Выбрать основу»**.
Для ручной основы выбирайте корень с `123/` и `panorama/` либо папку с VPK готового фона.
Актуальность сторонней основы после патчей игры проверяется отдельно.

## Видео: выбрать файл и готово

Нажмите **«+ Добавить видео»** и выберите MP4, WebM или другой формат, который читает FFmpeg.
Программа сохранит копию в библиотеке, создаст превью, растянет видео под физическое
разрешение экрана, конвертирует его в VP9/WebM, соберёт актуальный фикс события и установит фон.
Если Dota запущена, видео останется в библиотеке; закройте игру и нажмите **«Применить фон»**.

В библиотеку автоматически импортируются прежние пакеты и установленный фон. Если локально
подготовлен архив образцов `wftrmaked.rar`, его фоны тоже подхватываются; сам архив не поставляется.
Превью воспроизводится без звука.
Параметры VPK и пути не нужны при обычном добавлении.

Дополнительные параметры запуска не нужны. Старый `-language 123` из прежней версии
программы больше не подключает папку с фоном. При установке он удаляется из LaunchOptions
только для Dota 2, с сохранением остальных аргументов. Для первой миграции закройте Dota и Steam,
чтобы они не перезаписали свои настройки из памяти.

Программа читает `dota/cfg/boot.vcfg` и выбирает штатную папку аудиоязыка:
`dota_russian`, `dota_schinese` или `dota_koreana`. Если там английский, выбирается существующая языковая папка без установленного аудиопакета (сначала `russian`).
Язык текста (`UILanguage`) сохраняется. Если русский пакет озвучки не установлен, ожидается
английская озвучка по запасному пути игры; фактический звук проверяется запуском.

Разрешение берётся у активного физического монитора Hyprland; при недоступности Hyprland —
у экрана окна Qt. В настройках можно сохранить своё разрешение. Видео именно растягивается
без добавления полос: пропорции исходника при необходимости меняются. Существующие чёрные
полосы, уже записанные в самом видео, не удаляются. Копия исходника сохраняется отдельно.

Результат ограничен 20 МБ с запасом по битрейту, частота — 30 кадров/с, звук убирается.
Длительность сохраняется. При чрезмерно длинном видео программа просит выбрать более короткий
фрагмент, а не обрезает его незаметно. Исходники до 2 ГиБ; максимальное разрешение — 7680 по стороне.

## Фикс текущего события

В установленной версии игры обнаружена принудительная ссылка `override-background`:

- архив: `game/dota/pak01_dir.vpk`;
- управляющая разметка: `panorama/layout/dashboard.vxml_c`;
- сцена события: `panorama/layout/dashboard_background_monster_hoard_2026.vxml_c`;
- пользовательский видеофон: `panorama/layout/dashboard_background_last_match.vxml_c`.

`monster_hoard_2026` — внутреннее имя **Trove of Terror**: в самой сцене указан токен
`DOTA_MonsterHoard2026_TreasureTitle`, а в `resource/localization/dota_english.txt` его значение —
`Trove of Terror`. Quartero's Curios и Dark Carnival имеют отдельные ресурсы; они не выбраны
этой ссылкой главного экрана. Название события теперь читается из файлов игры, когда доступен
однозначный токен заголовка сокровищницы.

Старый `pak02` из гайда заменял целый dashboard времён Crownfall. Теперь приложение читает
**текущий dashboard установленной игры**, заменяет только строковую ссылку в скомпилированном
LaCo/KV3 v5, пересчитывает размеры и перепаковывает ресурс в отдельный `pak02_dir.vpk`.
Остальные блоки, таблица типов и числовые данные сохраняются. Старый фикс Crownfall исключается.

Фикс собирается при каждом применении фона. После обновления игры приложение сравнивает
размер и время изменения индекса VPK и предлагает обновить фикс. Кнопка **«Обновить фикс события»**
сохраняет установленное видео без конвертации. При неизвестной версии или неоднозначной ссылке
автоматическая замена останавливается с ошибкой.

При обновлении фикса видео сохраняется побайтно. Отчёт последнего исправления хранится в
`~/.local/share/dota-background-changer/last-scene-repair.json`, если исправление запускалось
с сохранением отчёта. Механизм проверен с Trove of Terror, но работа после будущих обновлений
не гарантируется; окончательный визуальный результат требует запуска Dota.

## Шрифты Dota 2

Вкладка **«Шрифты Dota»** показывает файлы из `game/dota/panorama/fonts` с поиском и переключателями.
Отключение сохраняет копию и SHA256, затем убирает файл из каталога игры; включение восстанавливает
проверенные байты. Резервные копии остаются после восстановления. Изменения требуют перезапуска игры.

Если Steam вернул или обновил шрифт, программа не перезапишет новую версию старой копией.
Проверка целостности Steam может вернуть отключённые шрифты. Эта вкладка управляет свободно
лежащими файлами шрифтов; зашифрованные или встроенные в другие архивы шрифты не удаляются.
Шрифты самой программы и системы не переключаются.

## Тема, хранение и восстановление

Палитра читается из `~/.local/state/omarchy/current/theme/colors.toml`, имя — из `theme.name`.
Открытое окно обновляет состояние и цвета каждые 12 секунд. В отсутствие Omarchy используется
встроенная тёмная палитра. Системная тема не редактируется.

Пользовательские данные находятся в `~/.local/share/dota-background-changer/`:

- `library/<id>/`: исходник, превью, подготовленные видео и собранные пакеты;
- `settings.json`: игра, основа, разрешение и данные миграции;
- `templates/local-base/`: локальная основа из предоставленного RAR;
- `fonts/<game-id>/`: резервные копии шрифтов и их состояния.

Фон устанавливается одним объединённым VPK в штатную папку аудиоязыка, например
`game/dota_russian/pak30_dir.vpk`. Номер выбирается среди свободных; чужие архивы и оригинальная
озвучка не перезаписываются. Перед установкой проверяются конфликты путей с другими VPK.
Служебный маркер `.dota-studio-install.json` содержит только имена файлов, принадлежащих программе.
При обновлении/отключении перемещаются только эти файлы, а не общая языковая папка.

Предыдущая установка сохраняется в `game/.dota-background-backups/`. Оригинальные VPK,
`gameinfo.gi` и подписи не меняются. В `boot.vcfg` изменяется только `AudioLanguage`; отключение
восстанавливает прежнее значение, если пользователь не изменил его самостоятельно.
Старый собственный пакет из `dota_123` при миграции архивируется.

Для отключения выберите **«Настройки → Отключить фон»**. Для возврата старого видео найдите его
в библиотеке и нажмите «Применить фон». Резервные копии автоматически не удаляются.
Старое значение LaunchOptions сохраняется отдельно в `steam-launch-backups/`; приватные
билеты и прочие данные Steam в эту копию не попадают.

Подробные пути и смена основы скрыты в **«Настройки → Подробности и пути»**.

## VPK и командная строка

Утилиты чтения VPK v1/v2, preload и многотомных архивов сохранены. Открывайте `*_dir.vpk`,
оставляя внешние тома рядом. Файлы проверяются по CRC32 при извлечении. Существующие файлы
не перезаписываются; скомпилированные ресурсы извлекаются как двоичные файлы.

```bash
./start.sh detect
./start.sh list /path/pak01_dir.vpk --filter panorama/layout
./start.sh extract /path/pak01_dir.vpk ./extracted --entry panorama/layout/dashboard.vxml_c
./start.sh pack ./assets ./new.vpk
./start.sh convert ./video.mp4 ./video.webm --width 1920 --height 1080
./start.sh scene --game "$HOME/.local/share/Steam/steamapps/common/dota 2 beta/game"
./start.sh repair-scene --game "$HOME/.local/share/Steam/steamapps/common/dota 2 beta/game"
./start.sh build --template ./template --video ./video.webm --output ./new-package \
  --game "$HOME/.local/share/Steam/steamapps/common/dota 2 beta/game"
```

Папки результата должны быть новыми. Полный список: `./start.sh --help`.

## Проверки и устройство

```bash
/usr/bin/python3 -m unittest discover -s tests -v
qmllint -I /usr/lib/qt6/qml qml/shell.qml qml/ActionButton.qml
/usr/bin/python3 tests/smoke_ui.py
```

29 тестов проверяют VPK, конвертацию настоящего MP4, создание превью, библиотеку, установку,
фикс события, сохранение блоков компилированной разметки, откат, шрифты и конфликты со Steam.
Тестовый запуск Quickshell рендерит все три вкладки в `.artifacts/`, без подключения к рабочему
столу. Кириллица и внешний вид проверены на этих изображениях. Реальная сессия Hyprland,
монитор через IPC и работа фона внутри игры остаются отдельной живой проверкой.

`qml/` — новое окно; `bridge.py` — JSON-протокол; `library.py` — библиотека и шрифты;
`media.py` — FFmpeg и мониторы; `mounts.py` — языковые папки и откат;
`steam_options.py` — точечная миграция старого аргумента Steam; `scene.py` — актуальный фикс; `core.py` — пакеты/установка;
`vpk.py` — архивы. `gui.py` и `gtk_gui.py` — запасные интерфейсы.

Основа: [исходный гайд](https://steamcommunity.com/sharedfiles/filedetails/?id=3360663587).
Формат ресурсов сверялся с [ValveResourceFormat](https://github.com/ValveResourceFormat/ValveResourceFormat),
архивы — с [ValvePython/vpk](https://github.com/ValvePython/vpk), окно — с
[Quickshell FloatingWindow](https://quickshell.org/docs/v0.2.0/types/Quickshell/FloatingWindow/).
Ресурсы игры и сторонние фоны не поставляются в исходном коде.

Актуальный механизм языковых папок сверялся с [документацией автора Dota 2 Mod Manager](https://dota2modmanager.com/docs/language/), а на этой машине — с `gameinfo.gi`, `boot.vcfg` и сохранёнными параметрами запуска. Наличие правильных файлов не заменяет проверку меню внутри игры.
